/**********************************************************************
 *  Problem A: 
 *  Compare this approach to the approach in HW2. Why is it better to 
 *  decompose a problem using objects?
 **********************************************************************/
It's better to decompose a problem using objects because it's easier to Implement
the the same method accross multiple bodies. In hw2 this was done manually but now
we can call the same methods for each body and can call different methods inside of 
other methods. In addition, it's easier to follow through the code with different
methods and comments helping you understand what each one does.
