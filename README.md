# CIS 1100

Java projects from an introductory programming course, Fall 2022. This repository is private.

## Projects

1. **Caesar.** Encrypts and decrypts text with a Caesar cipher, and cracks an unknown key using letter frequencies.
2. **NBody.** Simulates planets moving under gravity and animates them.
3. **NBody with objects.** Rebuilds the simulation with Body and Space classes and unit tests.
4. **Recursion.** Recursive exercises with tests, plus a Sierpinski triangle drawing.
5. **Rivalry.** An animated race between two electric cars, plus small drawing and text viewer programs.
6. **Sudoku.** A playable Sudoku board that checks moves against the rules.
7. **Irate Avians.** A physics game where you launch birds at targets.
8. **TSP.** Builds traveling salesperson tours with nearest neighbor and smallest increase heuristics, with unit tests.

Each folder has the source code and a readme describing the approach.
