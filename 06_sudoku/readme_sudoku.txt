/**********************************************************************
 * Instructions for how to run your program 
 * (which class to run, any command line arguments)
 **********************************************************************/
Run the program with java Sudoku filename. After entering in this the program
will do the rest of the work. To play, click the box you want to put the number
in and then type the number on the keyboard. Then, repeat the same process for
the other boxes. When the game is complete, a message will appear that you have won.

/**********************************************************************
 *  Any additional features you added beyond the assignment specifications                   
 **********************************************************************/
I added the extra credit feature where if you mouse press then click space
the board will clear.


/**********************************************************************
 *  A brief description of each file and its purpose
 **********************************************************************/
The Sudoku.java file will take in the command line arguments and complete
all necessary actions if the mouse and key are pressed.

The Field.java file will draw the board and digits, have getter functions,
and check the to make sure that there is no error in the Sudoku rules such as 
no similar number within columns, rows, or boxes.
